任务二：MuJoCo 四足机器人仿真
一、项目简介
本项目基于 Python 与 MuJoCo 物理仿真引擎，完成 Black 四足机器人 基础物理仿真搭建与基础控制功能开发。项目完成机器人模型格式转换、动力学参数配置、执行器配置、场景搭建，并实现了阻尼静置、姿态站立双模式切换控制，可稳定模拟四足机器人在重力、接触约束下的物理运动状态。
二、任务内容
1. 模型处理：将四足机器人原始 URDF 模型转换、优化并整理为 MuJoCo 标准 MJCF 模型文件，修正模型尺寸、碰撞、质心与惯量参数，适配物理仿真。
2. 动力学配置：为机器人机身添加 freejoint 自由关节，支持机身三维平动与三维旋转；对 12 个腿部关节逐一配置力矩型 Motor 执行器，实现关节力矩可控。
3. 仿真场景搭建：构建平坦地面物理场景，配置地面碰撞、摩擦参数，满足机器人静置、落地仿真条件。
4. 基础仿真实现：零控制输入（data.ctrl[:] = 0.0）下，机器人依靠自身重力与地面接触约束自然落地、稳定趴卧，完成基础动力学仿真验证。
5. 拓展控制功能：新增 阻尼模式、站立姿态模式 按键切换功能，通过 PD 控制实现机器人平滑起立，支持仿真状态实时切换。
三、开发环境
- 系统：Ubuntu
- Python 版本：3.10.12
- 仿真引擎：MuJoCo 3.1.4
- 依赖库：numpy、mujoco-python

五、核心功能说明
1. 阻尼模式（默认模式 / X键切换）
关闭姿态控制，仅通过关节速度阻尼抑制机器人抖动，零力矩输入，机器人受重力影响自然静置趴卧，用于验证模型动力学稳定性与碰撞合理性。
2. 站立模式（Z键切换）
采用平滑插值算法规划关节姿态，通过 PD 控制器计算关节力矩，限制最大输出扭矩，实现机器人从静置姿态平滑起立，姿态稳定、无剧烈震荡。
3. 仿真优化
采用物理仿真步与渲染步分离方案，高频运行物理迭代、低频画面渲染，解决原生同步渲染导致的慢动作、仿真卡顿问题，保证物理时序精准的同时提升仿真流畅度。
六、运行方式
pip install -r requirements.txt
进入项目脚本目录，直接运行仿真脚本：
cd 02_mujoco_quadruped/scripts
python3 simulate.py
按键操作：
- Z：切换为站立姿态模式
- X：切换为阻尼静置模式
